Instalación de VirtualBox y AlmaLinux 9

Curso: Sistemas Operativos

Carrera: Análisis de Sistemas Informáticos

Material didáctico · UTIC

1. Introducción

En esta unidad práctica aprenderemos a instalar y configurar un entorno de virtualización utilizando VirtualBox, y sobre él instalaremos una máquina virtual con AlmaLinux 9, una distribución de Linux orientada a servidores y de uso profesional.

Este proceso permite experimentar con sistemas operativos, probar comandos, crear archivos y directorios, y comprender el funcionamiento de un sistema Linux sin necesidad de modificar la computadora física del estudiante.

Importante: trabajar con máquinas virtuales permite cometer errores, reinstalar el sistema y practicar libremente sin poner en riesgo el equipo real.

2. ¿Qué es VirtualBox, dónde nació y para qué se usa?

VirtualBox es un software de virtualización de tipo hipervisor (Tipo 2 o "hosted") que permite crear y ejecutar máquinas virtuales: computadoras simuladas por software que funcionan dentro de una computadora física, llamada equipo anfitrión (host).

Origen de VirtualBox

VirtualBox fue creado originalmente por la empresa alemana Innotek GmbH, que lanzó su primera versión en enero de 2007. En 2008, Innotek fue adquirida por Sun Microsystems, que continuó el desarrollo del proyecto como software libre y gratuito. Finalmente, en 2010, cuando Oracle Corporation adquirió Sun Microsystems, el producto pasó a llamarse oficialmente Oracle VM VirtualBox, nombre que conserva hasta la actualidad.

¿Para qué se utiliza?

  • Probar distintos sistemas operativos sin instalarlos físicamente.
  • Crear laboratorios de práctica para estudiantes de informática.
  • Desarrollar y probar software en entornos aislados.
  • Simular servidores, redes y entornos de producción de forma segura.
  • Realizar copias de seguridad completas del sistema (snapshots).
Característica Descripción
Tipo de hipervisor Tipo 2 (se ejecuta sobre un sistema operativo anfitrión).
Licencia Software gratuito y de código abierto (GPL), propiedad de Oracle.
Sistemas anfitriones soportados Windows, Linux, macOS.
Sistemas invitados soportados Windows, Linux, BSD, Solaris, macOS (bajo ciertas condiciones), entre otros.

3. Instalación de VirtualBox

A continuación se detallan los pasos generales para instalar VirtualBox en un equipo con Windows como sistema anfitrión.

Requisito: antes de instalar, verificar que la virtualización (VT-x/AMD-V) esté habilitada en la BIOS/UEFI del equipo.
  1. Descargar el instalador Ingresar al sitio oficial virtualbox.org y descargar el paquete correspondiente al sistema operativo anfitrión (por ejemplo, "Windows hosts").
  2. Ejecutar el instalador Hacer doble clic sobre el archivo .exe descargado y aceptar los permisos de administrador solicitados.
  3. Asistente de instalación Seguir el asistente, aceptando las opciones predeterminadas de componentes (VirtualBox USB, red, accesos directos).
  4. Advertencia de red El instalador puede reiniciar temporalmente los adaptadores de red del equipo para instalar sus controladores; esto es normal.
  5. Finalizar instalación Al finalizar, VirtualBox se abre automáticamente mostrando el Administrador de máquinas virtuales.
  6. (Opcional) Instalar Extension Pack Descargar el "Oracle VM VirtualBox Extension Pack" para agregar soporte de USB 2.0/3.0, arranque por red y otras funciones adicionales.

4. Crear una máquina virtual

Una vez instalado VirtualBox, el siguiente paso es crear la máquina virtual donde se instalará AlmaLinux 9.

  1. Nueva máquina En el Administrador de VirtualBox, hacer clic en Nueva.
  2. Nombre, carpeta y tipo Escribir un nombre (por ejemplo, AlmaLinux9). VirtualBox detecta automáticamente Tipo: Linux y Versión: Red Hat (64-bit) u Oracle Linux (64-bit).
  3. Memoria RAM Asignar memoria para la máquina virtual. Se recomienda 2048 MB (2 GB) como mínimo, idealmente 4 GB.
  4. Disco duro virtual Seleccionar Crear un disco duro virtual ahora y elegir el tipo VDI (VirtualBox Disk Image).
  5. Almacenamiento Elegir Reservado dinámicamente, para que el disco crezca según se use.
  6. Tamaño del disco Asignar como mínimo 20 GB para AlmaLinux 9.
  7. Crear Confirmar y la máquina virtual aparecerá en la lista, apagada, lista para instalar el sistema operativo.
Recurso Mínimo recomendado
Procesadores (CPU) 1 - 2 núcleos
Memoria RAM 2 GB (recomendado 4 GB)
Disco duro 20 GB o más
Tarjeta de red NAT (por defecto) o Adaptador puente

5. Instalar un sistema operativo AlmaLinux 9

  1. Descargar la imagen ISO Descargar el archivo .iso de AlmaLinux 9 desde el sitio oficial almalinux.org (versión DVD o Minimal).
  2. Montar la ISO en la máquina virtual En Configuración → Almacenamiento, seleccionar la unidad óptica vacía y elegir el archivo ISO descargado.
  3. Iniciar la máquina virtual Hacer clic en Iniciar; la máquina arrancará desde la imagen ISO y se abrirá el instalador gráfico Anaconda.
  4. Seleccionar idioma Elegir el idioma de instalación (por ejemplo, Español).
  5. Resumen de instalación Configurar: teclado, fecha/hora, destino de instalación (disco virtual), conexión de red y selección de software (por ejemplo, "Servidor con GUI" o "Servidor mínimo").
  6. Destino de instalación Seleccionar el disco virtual y elegir el particionado (automático o manual, ver sección 8).
  7. Contraseña de root y usuario Definir la contraseña de administrador (root) y crear un usuario estándar para el uso diario.
  8. Comenzar la instalación Hacer clic en Comenzar instalación y esperar a que el proceso finalice.
  9. Reiniciar Al finalizar, hacer clic en Reiniciar sistema y retirar la ISO virtual para arrancar desde el disco instalado.
Listo: al reiniciar, el sistema mostrará la pantalla de inicio de sesión de AlmaLinux 9, confirmando que la instalación fue exitosa.

6. ¿Qué es Linux? (breve introducción)

Linux es un núcleo (kernel) de sistema operativo de código abierto, creado en 1991 por el estudiante finlandés Linus Torvalds. El kernel es el componente que se comunica directamente con el hardware y administra los recursos del sistema (procesador, memoria, dispositivos).

Alrededor de este núcleo se construyen las distribuciones de Linux (distros): conjuntos de software (kernel + herramientas + gestor de paquetes + entorno gráfico opcional) empaquetados para el uso final. Ejemplos: Ubuntu, Debian, Fedora, AlmaLinux, openSUSE, entre otras.

Dato: Linux es gratuito, modificable y ampliamente utilizado en servidores, supercomputadoras, dispositivos móviles (Android) y sistemas embebidos.

7. ¿Qué es AlmaLinux? Origen y diferencias con RHEL

AlmaLinux es una distribución de Linux de tipo empresarial, orientada a servidores, gratuita y de código abierto.

Origen

AlmaLinux fue creada en marzo de 2021 por la empresa CloudLinux Inc., como respuesta a la decisión de Red Hat de convertir a CentOS en CentOS Stream (una rama de desarrollo previa a RHEL, en lugar de un clon estable). AlmaLinux nació para ocupar el espacio que dejó CentOS como distribución 1:1 compatible con Red Hat Enterprise Linux, y actualmente es gestionada por la AlmaLinux OS Foundation, una organización sin fines de lucro.

Diferencias entre AlmaLinux y RHEL

RHEL (Red Hat Enterprise Linux)

  • Distribución comercial de Red Hat / IBM.
  • Requiere suscripción/licencia paga para soporte y actualizaciones.
  • Incluye soporte técnico oficial de Red Hat.
  • Muy utilizada en grandes empresas con contratos de soporte.

AlmaLinux

  • Distribución gratuita y de código abierto.
  • Binariamente compatible (1:1) con RHEL.
  • Sin costo de licencia; soporte comunitario.
  • Ideal para estudiantes, laboratorios, servidores propios y empresas que buscan reducir costos.
Aspecto RHEL AlmaLinux
Costo Pago (suscripción) Gratuito
Código fuente Abierto, restringido en su distribución binaria Abierto
Compatibilidad Base original 1:1 compatible con RHEL
Soporte Oficial de Red Hat Comunidad / AlmaLinux OS Foundation

8. Particionado y tipo de sistema de archivos

Durante la instalación de AlmaLinux 9, el instalador permite definir cómo se dividirá el disco duro virtual en particiones.

Partición Función
/boot Almacena el kernel y los archivos necesarios para el arranque del sistema.
swap Memoria de intercambio en disco, utilizada cuando la RAM se satura.
/ (root) Partición raíz; contiene el sistema operativo y sus archivos principales.
/home Almacena los archivos y configuraciones de los usuarios.

Tipos de sistema de archivos

El sistema de archivos define cómo se organizan y almacenan los datos dentro de una partición.

Sistema de archivos Descripción
XFS Sistema de archivos por defecto en AlmaLinux/RHEL 9. Alto rendimiento con archivos grandes.
ext4 Muy utilizado en distintas distribuciones Linux; estable y confiable.
Btrfs Sistema de archivos moderno con soporte para snapshots y compresión.
FAT32/NTFS Utilizados principalmente en Windows; Linux puede leerlos/montarlos.
Recomendación para el laboratorio: utilizar el particionado automático del instalador y dejar XFS como sistema de archivos predeterminado.

9. Comandos básicos de Linux (Fedora/RHEL y Debian)

Los comandos de navegación y manejo de archivos son en su mayoría iguales en todas las distribuciones de Linux. Las diferencias principales aparecen en los gestores de paquetes, ya que AlmaLinux (basado en Fedora/RHEL) utiliza dnf, mientras que distribuciones basadas en Debian (como Ubuntu) utilizan apt.

Comandos generales de navegación y archivos

Comando Explicación
pwd Muestra el directorio (carpeta) en el que se encuentra el usuario actualmente.
ls Lista los archivos y directorios contenidos en la carpeta actual.
ls -l Lista los archivos con detalles: permisos, propietario, tamaño y fecha.
cd nombre_carpeta Cambia de directorio (se mueve hacia otra carpeta).
cd .. Retrocede un nivel, hacia la carpeta superior.
mkdir nombre Crea un nuevo directorio (carpeta).
touch archivo Crea un archivo vacío.
rm archivo Elimina un archivo.
rm -r carpeta Elimina una carpeta y todo su contenido.
cp origen destino Copia un archivo o carpeta.
mv origen destino Mueve o renombra un archivo o carpeta.
cat archivo Muestra el contenido de un archivo de texto en pantalla.
sudo comando Ejecuta un comando con permisos de administrador (superusuario).
clear Limpia la pantalla de la terminal.

Gestión de paquetes: Fedora/RHEL (AlmaLinux) vs Debian

AlmaLinux 9, al estar basado en la familia Fedora/RHEL, utiliza el gestor de paquetes dnf. Distribuciones como Ubuntu o Debian utilizan apt. Ambos cumplen la misma función: instalar, actualizar y eliminar programas.

Acción Fedora / RHEL / AlmaLinux (dnf) Debian / Ubuntu (apt)
Actualizar lista de paquetes sudo dnf check-update sudo apt update
Actualizar el sistema sudo dnf update sudo apt upgrade
Instalar un paquete sudo dnf install nombre sudo apt install nombre
Eliminar un paquete sudo dnf remove nombre sudo apt remove nombre
Buscar un paquete dnf search nombre apt search nombre
Nota: aunque los comandos de administración de paquetes cambian entre familias de distribuciones, los comandos básicos de navegación y manejo de archivos (ls, cd, mkdir, rm, etc.) son los mismos en cualquier distribución Linux.

10. Pasos para crear un directorio

Un directorio (carpeta) permite organizar archivos dentro del sistema. Se crea con el comando mkdir (make directory).

  1. Abrir la terminal En AlmaLinux, abrir una terminal desde el menú de aplicaciones o presionando Ctrl + Alt + T (según el entorno gráfico).
  2. Ubicarse en la carpeta deseada Usar cd para moverse hasta el lugar donde se creará el nuevo directorio. Ejemplo: cd /home/usuario
  3. Ejecutar el comando mkdir Escribir mkdir nombre_carpeta y presionar Enter.
  4. Verificar la creación Ejecutar ls para comprobar que la nueva carpeta aparece en el listado. 
$ cd /home/usuario
$ mkdir practica01
$ ls
practica01
Tip: el parámetro -p permite crear varias carpetas anidadas de una sola vez, por ejemplo: mkdir -p proyectos/os/practica01

11. Pasos para crear un archivo

En Linux existen varias formas de crear archivos desde la terminal. Las más comunes son con el comando touch (para archivos vacíos) o con editores de texto como nano o vi.

Opción 1: crear un archivo vacío con touch

  1. Ubicarse en el directorio deseado Usar cd para posicionarse en la carpeta correspondiente.
  2. Ejecutar touch Escribir touch nombre_archivo.txt y presionar Enter.
  3. Verificar Ejecutar ls para confirmar que el archivo fue creado. 
$ cd practica01
$ touch notas.txt
$ ls
notas.txt

Opción 2: crear un archivo con contenido usando nano

  1. Abrir el editor Escribir nano nombre_archivo.txt y presionar Enter.
  2. Escribir el contenido Redactar el texto deseado dentro del editor.
  3. Guardar Presionar Ctrl + O y luego Enter para guardar los cambios.
  4. Salir Presionar Ctrl + X para cerrar el editor. 
$ nano notas.txt
(escribir contenido)
Ctrl + O   → guardar
Enter      → confirmar nombre
Ctrl + X   → salir
Resultado: el archivo quedará almacenado en el directorio actual y podrá visualizarse con el comando cat notas.txt.

12. Conclusión

La virtualización con VirtualBox permite experimentar con sistemas operativos como AlmaLinux 9 de forma segura y controlada. Conocer el origen de las herramientas utilizadas, el particionado del disco, los sistemas de archivos y los comandos básicos de Linux es fundamental para desenvolverse en el estudio y la administración de sistemas operativos.

Idea fundamental: la práctica constante en un entorno virtual es la mejor forma de aprender Linux sin riesgo para el equipo físico.
