1. Introducción a los Sistemas Operativos

Un sistema operativo (SO) es el software fundamental que permite administrar los recursos de una computadora y proporcionar servicios a los programas y usuarios.

Sin un sistema operativo, el usuario tendría que comunicarse directamente con los componentes físicos mediante instrucciones de muy bajo nivel.

Idea fundamental: El sistema operativo permite que el usuario y las aplicaciones utilicen los recursos del hardware de una manera organizada, segura y eficiente.

3. ¿Qué es un Sistema Operativo?

Definición

Un sistema operativo es un conjunto de programas que administra los recursos físicos y lógicos de una computadora y proporciona un entorno para la ejecución de aplicaciones.

Entre los recursos administrados se encuentran el procesador, la memoria, los dispositivos de almacenamiento y los dispositivos de entrada y salida.

Concepto clave: El sistema operativo no es solamente una interfaz gráfica. Es el software encargado de coordinar numerosos recursos y servicios necesarios para que el sistema informático funcione.

5. Objetivos y Funciones del Sistema Operativo

El sistema operativo tiene como objetivo principal administrar los recursos de la computadora y proporcionar un entorno adecuado para la ejecución de programas.

🧠

Gestión del procesador

Administra la utilización de la CPU y coordina la ejecución de los programas.

💾

Gestión de memoria

Controla la utilización de la memoria principal y asigna espacio a los programas.

📁

Gestión de archivos

Proporciona mecanismos para organizar, almacenar, consultar y administrar archivos.

🔌

Gestión de dispositivos

Coordina el acceso a dispositivos como teclado, mouse, impresoras, discos y otros periféricos.

🔐

Seguridad y protección

Controla el acceso a recursos y ayuda a proteger la información y los procesos del sistema.

🖱️

Interfaz de usuario

Permite al usuario interactuar con el sistema mediante interfaces gráficas o de línea de comandos.

Resumen de funciones

Recurso Función del sistema operativo
CPU Coordinar la ejecución de programas y procesos.
Memoria Asignar y controlar el uso de la memoria.
Almacenamiento Organizar y administrar archivos y datos.
Periféricos Controlar la comunicación con los dispositivos.
Usuarios Controlar el acceso y proporcionar una interfaz.

6. Evolución Histórica de los Sistemas Operativos

Los sistemas operativos evolucionaron junto con el hardware y las necesidades de los usuarios. Las primeras computadoras no disponían de los sistemas operativos modernos que conocemos actualmente.

Década de 1940

Primeras computadoras

Las primeras computadoras electrónicas se utilizaban principalmente para cálculos científicos y militares. La interacción con la máquina era limitada y los programas se ejecutaban de manera muy cercana al hardware.

Década de 1950

Procesamiento por lotes

Aparecen mecanismos para agrupar trabajos y ejecutarlos de forma secuencial. El objetivo era aprovechar mejor el tiempo de procesamiento de las computadoras.

Década de 1960

Multiprogramación y tiempo compartido

Los sistemas comienzan a administrar varios trabajos y usuarios, buscando utilizar de manera más eficiente los recursos del procesador y la memoria.

Década de 1970

UNIX y nuevos enfoques

UNIX se convierte en un sistema operativo de gran importancia histórica por sus conceptos de diseño, portabilidad y utilización en diferentes entornos.

Décadas de 1980 y 1990

Computación personal

La expansión de las computadoras personales impulsa sistemas operativos orientados al usuario final y posteriormente interfaces gráficas cada vez más accesibles.

Actualidad

Sistemas conectados y multidispositivo

Los sistemas operativos actuales funcionan en computadoras, servidores, teléfonos inteligentes, dispositivos embebidos y otros equipos conectados.

Importante: La evolución de los sistemas operativos está relacionada directamente con la evolución del hardware, las redes, las aplicaciones y las necesidades de los usuarios.

7. Tipos de Sistemas Operativos

Los sistemas operativos pueden clasificarse de diferentes maneras según el tipo de equipo, cantidad de usuarios, forma de procesamiento o propósito para el que fueron diseñados.

🖥️

Escritorio

Diseñados para computadoras personales y estaciones de trabajo.

Ejemplos:

Windows, GNU/Linux y macOS.

🗄️

Servidores

Diseñados para proporcionar servicios y recursos a otros equipos mediante una red.

Ejemplos:

Linux Server y Windows Server.

📱

Móviles

Diseñados para teléfonos inteligentes y dispositivos móviles.

Ejemplos:

Android e iOS.

⚡

Tiempo real

Diseñados para responder a eventos dentro de restricciones temporales determinadas.

Aplicaciones:

Control industrial, robótica y sistemas críticos.

🔧

Embebidos

Funcionan dentro de dispositivos diseñados para realizar funciones específicas.

Aplicaciones:

Automóviles, electrodomésticos, dispositivos IoT.

🌐

Distribuidos

Permiten coordinar recursos y servicios ubicados en diferentes equipos conectados.

Característica:

Coordinación de recursos mediante redes.

8. Comparación de Algunos Tipos de Sistemas Operativos

Tipo Propósito Ejemplos / Aplicaciones
Escritorio Uso personal y profesional. Windows, GNU/Linux, macOS.
Servidor Proporcionar servicios y recursos en red. Servidores web, bases de datos, archivos.
Móvil Administrar dispositivos portátiles. Android, iOS.
Tiempo real Responder a eventos dentro de tiempos determinados. Automatización, robótica y control.
Embebido Controlar dispositivos específicos. IoT, vehículos, electrodomésticos.
Distribuido Coordinar recursos de diferentes equipos. Sistemas conectados y entornos distribuidos.

Actividad 1 — Comprensión conceptual

  1. ¿Qué es un sistema operativo?
  2. ¿Por qué se considera al sistema operativo un intermediario entre el usuario y el hardware?

  4. ¿Cuál es la función de la gestión de memoria?
  5. ¿Qué función cumple la gestión de archivos?
  6. ¿Por qué la evolución del hardware influyó en la evolución de los sistemas operativos?
  7. ¿Qué diferencia existe entre un sistema operativo de escritorio y uno para dispositivos móviles?

Actividad 2 — Análisis

Analiza el siguiente escenario:

Una computadora posee un procesador, memoria RAM, almacenamiento SSD, teclado, mouse y monitor. El usuario desea ejecutar un procesador de textos.

Explica qué papel desempeña el sistema operativo para permitir que el usuario pueda utilizar el procesador de textos.

Actividad 3 — Investigación

Investiga la evolución de un sistema operativo de tu elección y construye una línea de tiempo con al menos cinco versiones importantes.

10. Resumen de la Parte 1

💡
Concepto principal

El sistema operativo es el software fundamental encargado de administrar los recursos de una computadora y proporcionar servicios para las aplicaciones y los usuarios.

Sus funciones incluyen la administración del procesador, memoria, archivos y dispositivos, además de proporcionar mecanismos de interacción, protección y control de los recursos.
