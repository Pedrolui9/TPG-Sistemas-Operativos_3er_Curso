Unidad 6: Sistemas de Archivos

Curso: Sistemas Operativos

Temas: Archivos · Directorios · Implementación · Seguridad · Mecanismos de protección

Material didáctico · UTIC

1. Sistemas de Archivos

Un sistema de archivos es la parte del sistema operativo encargada de organizar, almacenar, localizar y proteger la información guardada en dispositivos como discos duros, unidades SSD, memorias USB y tarjetas de memoria.

Cuando una persona crea una carpeta o guarda un documento, el sistema operativo debe registrar dónde se encuentra esa información, qué nombre tiene, cuánto ocupa y quién puede utilizarla. El sistema de archivos hace posible que el usuario trabaje con nombres y carpetas sin tener que conocer la ubicación física exacta de los datos en el dispositivo.

Ejemplos: FAT32, NTFS, ext4, XFS y Btrfs son sistemas de archivos utilizados en distintos sistemas operativos y dispositivos.
Para exponer: “El sistema de archivos es el encargado de organizar la información. Nosotros vemos carpetas y nombres, pero el sistema operativo debe saber en qué bloques del disco están realmente guardados esos datos.”

2. Archivos

Un archivo es una colección de información relacionada almacenada bajo un nombre. Puede contener texto, imágenes, música, videos, programas, bases de datos u otros tipos de información.

Atributos principales de un archivo

Nombre

Permite identificar el archivo, por ejemplo informe.pdf.

Tamaño

Indica cuánto espacio ocupa en el dispositivo de almacenamiento.

Ubicación

Señala dónde se encuentra dentro de la estructura del sistema de archivos.

Permisos

Determinan quién puede leer, modificar o ejecutar el archivo.

Operaciones comunes

  • Crear: generar un nuevo archivo.
  • Abrir: preparar el archivo para ser utilizado.
  • Leer: consultar su contenido.
  • Escribir: agregar o modificar información.
  • Renombrar: cambiar su nombre.
  • Copiar o mover: duplicarlo o cambiarlo de ubicación.
  • Eliminar: quitarlo del sistema de archivos.

Métodos de acceso

Método Descripción Ejemplo sencillo
Secuencial Los datos se leen en orden, uno detrás de otro. Leer un archivo de texto desde el principio hasta el final.
Directo Se puede acceder directamente a una parte determinada del archivo. Ir a una posición concreta dentro de una base de datos.
Indexado Se utiliza una estructura de índice para localizar la información. Buscar un registro utilizando una referencia.
Para exponer: “Un archivo no es solamente su contenido. También posee información como nombre, tamaño, ubicación y permisos, que el sistema operativo utiliza para administrarlo.”

3. Directorios

Un directorio, también llamado carpeta, es una estructura utilizada para organizar archivos y otros directorios. La forma más común de organización es jerárquica, similar a un árbol.

/ ├── documentos │ ├── tarea.pdf │ └── informe.txt ├── imagenes │ ├── foto.jpg │ └── logo.png └── programas └── ejemplo.exe

Directorio raíz

Es el punto principal desde el cual comienza la estructura de carpetas. A partir de él se crean directorios y subdirectorios.

Rutas absolutas y relativas

  • Ruta absoluta: muestra la ubicación completa desde la raíz. Ejemplo: /documentos/tarea.pdf.
  • Ruta relativa: indica la ubicación desde el directorio en el que se encuentra actualmente el usuario.

Operaciones con directorios

Los directorios pueden crearse, eliminarse, renombrarse, copiarse, moverse y utilizarse para buscar o clasificar archivos.

Ventaja principal: la estructura de directorios permite mantener la información ordenada y facilita la búsqueda de archivos.
Para exponer: “Los directorios funcionan como una estructura de organización. Gracias a ellos podemos separar documentos, imágenes y programas en diferentes carpetas y subcarpetas.”

4. Implementación de Sistemas de Archivos

La implementación explica cómo el sistema operativo transforma la estructura lógica que ve el usuario —archivos y carpetas— en datos almacenados físicamente dentro del dispositivo.

Bloques de almacenamiento

Los dispositivos se dividen en pequeñas unidades llamadas bloques. Cuando un archivo se guarda, el sistema de archivos debe asignarle uno o varios de esos bloques.

Métodos de asignación

Método Funcionamiento Característica
Contigua Los bloques del archivo se almacenan uno después de otro. Es simple y rápida, pero puede dificultar el crecimiento del archivo.
Enlazada Cada bloque guarda una referencia al siguiente. Permite utilizar bloques dispersos en el disco.
Indexada Se utiliza un bloque índice con las direcciones de los bloques del archivo. Facilita el acceso directo a diferentes partes del archivo.

Administración del espacio libre

El sistema operativo también debe registrar qué bloques están ocupados y cuáles permanecen libres. Una técnica común es el mapa de bits, donde cada bit representa el estado de un bloque.

Ejemplos importantes

Sistema de archivos Uso general
FAT / FAT32 Muy conocido por su compatibilidad con memorias USB y dispositivos diversos.
NTFS Utilizado principalmente por Windows y dispone de funciones de permisos y administración avanzada.
ext4 Muy utilizado en sistemas Linux.
XFS Sistema de archivos utilizado en entornos Linux y orientado al manejo eficiente de grandes volúmenes de datos.
Btrfs Sistema moderno para Linux con funciones avanzadas de administración de almacenamiento.
Para exponer: “La implementación es la parte interna. El usuario ve un archivo, pero el sistema operativo debe decidir en qué bloques guardarlo y cómo encontrar esos bloques más tarde.”

5. Seguridad

La seguridad de los archivos busca evitar que la información sea utilizada, modificada, eliminada o divulgada por personas que no están autorizadas.

Principales riesgos

  • Acceso no autorizado a documentos privados.
  • Modificación accidental o intencional de archivos.
  • Eliminación de información importante.
  • Daños producidos por programas maliciosos.
  • Pérdida de información por fallas del dispositivo.

Medidas básicas de seguridad

Usuarios

Cada persona puede tener una cuenta con determinados privilegios.

Autenticación

Permite comprobar la identidad de quien intenta acceder al sistema.

Copias de seguridad

Permiten recuperar información cuando un archivo se pierde o se daña.

Cifrado

Protege el contenido transformándolo para que solo pueda ser interpretado con autorización.

Importante: guardar información no es suficiente. También es necesario controlar quién puede utilizarla y disponer de mecanismos de recuperación.
Para exponer: “La seguridad busca proteger los datos frente a accesos no autorizados, pérdida, modificación o eliminación. Por eso se utilizan usuarios, contraseñas, copias de seguridad y otros controles.”

6. Mecanismos de Protección

Los mecanismos de protección son las herramientas que utiliza el sistema operativo para controlar qué acciones puede realizar cada usuario sobre un archivo o directorio.

Permisos básicos

Permiso Símbolo Permite
Lectura r Consultar el contenido de un archivo.
Escritura w Modificar o agregar información.
Ejecución x Ejecutar un archivo cuando se trata de un programa o script.

Propietario, grupo y otros

En sistemas tipo UNIX/Linux, los permisos suelen organizarse en tres grupos: propietario, grupo y otros usuarios.

Ejemplo: rwxr-xr--
Propietario: lectura, escritura y ejecución.
Grupo: lectura y ejecución.
Otros: solo lectura.

Otros mecanismos

  • Listas de Control de Acceso (ACL): permiten definir permisos específicos para distintos usuarios.
  • Cifrado: protege el contenido del archivo frente a personas no autorizadas.
  • Copias de seguridad: permiten restaurar datos perdidos o dañados.
  • Registro de actividades: ayuda a controlar acciones realizadas sobre la información.

7. Conclusión

Los sistemas de archivos son una parte fundamental de los sistemas operativos, ya que permiten organizar, almacenar, localizar y proteger la información guardada en los dispositivos de almacenamiento.

Mediante los archivos y directorios, el usuario puede mantener sus datos de forma ordenada, mientras que internamente el sistema operativo administra los bloques de almacenamiento, los permisos de acceso y los mecanismos de protección.

Además, la seguridad es un aspecto esencial, por lo que se utilizan herramientas como permisos, listas de control de acceso, cifrado y copias de seguridad para evitar accesos no autorizados y reducir el riesgo de pérdida de información.

En resumen: un sistema de archivos no solo guarda datos, sino que también los organiza, administra y protege para que puedan ser utilizados de manera eficiente y segura.
