1. Dispositivos de E/S y Principios de Software

Los dispositivos de Entrada/Salida se clasifican principalmente en tres categorías:

  • Legibles por el usuario: Teclado, mouse, monitor, impresoras.
  • Legibles por la máquina: Discos duros, SSDs, controladores USB.
  • De comunicación: Tarjetas de red (NIC), módems.

Principios del Software de E/S

El objetivo principal del software de E/S es la independencia del dispositivo, la asignación de nombres uniforme, la gestión de errores en la capa más baja posible y la transferencia bloqueante vs. no bloqueante.

2. Organización del Sistema de E/S

La E/S se puede ejecutar mediante tres técnicas principales de comunicación entre CPU y el dispositivo:

  • E/S Programada: La CPU espera activamente (polling) a que el módulo de E/S complete la operación. Es ineficiente.
  • E/S Dirigida por Interrupciones: La CPU emite el comando y continúa haciendo otro trabajo. El controlador interrumpe a la CPU cuando está listo.
  • Acceso Directo a Memoria (DMA): Un controlador especial (DMA) gestiona la transferencia directa de bloques de datos entre los periféricos y la memoria RAM sin pasar contínuamente por la CPU.

3. Aspectos de Diseño del Sistema Operativo

El Sistema Operativo busca cumplir dos objetivos clave en la gestión de E/S:

  1. Eficiencia: La E/S suele ser el cuello de botella del sistema debido a la diferencia de velocidad entre la memoria/CPU y los periféricos mecánicos o de red.
  2. Generalidad: Tratar a todos los dispositivos de la forma más uniforme posible (ejemplo: en UNIX todo se maneja como un archivo).

4. Utilización de Buffers de E/S

El buferizado guarda datos en memoria temporal para suavizar los picos de transferencia e independizar el ritmo de la CPU del periférico:

  • Sin Buferizado: El SO transfiere directamente entre dispositivo y proceso.
  • Buferizado Único: El SO asigna una memoria intermedia en RAM para leer el bloque antes de pasarlo al usuario.
  • Buferizado Doble (Ping-Pong): Mientras un proceso consume datos de un búfer, el dispositivo llena el segundo búfer.
  • Buferizado Circular: Se utiliza una cola circular de dos o más búferes para amortiguar ráfagas masivas de transferencia.

5. Planificación del Disco

Para discos mecánicos (HDD), el tiempo de acceso depende del movimiento del cabezal. Los algoritmos optimizan el orden de lectura:

  • FIFO (First-In, First-Out): Atiende en orden de llegada. Justo pero ineficiente.
  • SSTF (Shortest Seek Time First): Atiende la solicitud más cercana a la posición actual del cabezal. Puede provocar starvation (inaniación).
  • SCAN (Algoritmo del Ascensor): El cabezal se mueve de un extremo al otro barriendo todas las peticiones en su camino.
  • C-SCAN (Circular SCAN): Barre en una sola dirección y vuelve al principio sin atender peticiones en el retorno para asegurar uniformidad.

6. RAID y Caché de Disco

Estructura RAID (Redundant Array of Independent Disks)

  • RAID 0: Distribuido (Striping). Mayor velocidad, sin redundancia.
  • RAID 1: Espejo (Mirroring). Duplicado completo de datos, alta tolerancia a fallos.
  • RAID 5: Paridad distribuida. Combina alta velocidad, almacenamiento eficiente y tolerancia a la falla de 1 disco.
  • RAID 6: Doble paridad distribuida. Soporta la falla simultánea de 2 discos.

Caché de Disco (Page Cache)

Memoria RAM asignada para almacenar bloques de disco leídos recientemente, reduciendo drásticamente las lecturas físicas al almacenamiento.

7. Comparativa de Sistemas de E/S en SOs

  • UNIX SVR4: Utiliza tablas de dispositivos estructuradas como archivos de caracteres o de bloques. Integra streams para comunicación modular de periféricos.
  • Linux: Separa dispositivos en tres grandes tipos (Character, Block, Network). Implementa el Scheduler I/O (Deadline, BFQ) y una potente Page Cache unificada.
  • Windows: Modelo basado en controladores por capas (WDM / KMDF). Toda operación de E/S genera un paquete **IRP** (I/O Request Packet) que viaja a través de los drivers.

8. Discos, Relojes y Terminales

  • Discos: Control de bloques, cilindros y pistas. Transición de direccionamiento CHS al moderno LBA (Logical Block Addressing).
  • Relojes (Clocks): Generan interrupciones periódicas necesarias para el rebanado de tiempo (time-slicing), contadores del sistema y alarmas.
  • Terminales: Manejo de entrada por teclado (modo canónico vs. modo no canónico/raw) y salida por pantalla mediante buffers de texto o framebuffers.
